# Transportes Aldunate

Pagina web simple para cotizar por WhatsApp.

## Como dejarla visible en internet

1. Entra a https://github.com/dahaka-31/transportes-aldunate
2. Toca Settings (Configuracion)
3. En el menu izquierdo toca Pages
4. En Source elige Deploy from a branch
5. Branch: main  /  carpeta: / (root)
6. Guarda

En 1 o 2 minutos la pagina queda en:
https://dahaka-31.github.io/transportes-aldunate/

El boton de WhatsApp todavia tiene un numero de prueba. Cuando el cliente pase el numero real, se cambia.
